# source_assets/

Arquivos-fonte da arte: `.blend`, `.kra`, `.svg` originais (os binários vão para o **Git LFS**).

Ficam **fora** do projeto Godot de propósito, para o Godot não tentar importá-los. O que o jogo usa é o
resultado exportado (`.glb`, `.png`…) dentro de `godot/content/`.

Padrões de modelagem e o passo a passo de um carro:
[`docs/plano/04-padroes-de-arte-e-pipeline-de-carros.md`](../docs/plano/04-padroes-de-arte-e-pipeline-de-carros.md).
